# CODSOFT Web Development Internship: Tasks

Extract the whole zip, then double-click **`index.html`** in this folder. It links to all three projects.

| Folder | Task | Open |
|---|---|---|
| `01-3d-landing-page` | Landing Page (Level 1) | `index.html` (needs internet for 3D library and fonts) |
| `02-quiz-maker` | Online Quiz Maker (Level 2) | `index.html` |
| `03-ecommerce` | E-Commerce Website, NOVA SUPPLY (Level 3) | `double-click-to-run.html` for a quick preview. The full React + Express app needs Node.js (see `03-ecommerce/README.md`) |

Tasks 01 and 02: every `index.html` is one self-contained file, so it also works if you move it somewhere else.
The optional React version of the quiz maker is in `02-quiz-maker/react-version/` (needs Node.js and `npm install`).
